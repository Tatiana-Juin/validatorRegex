# ValidatorRegex

Un outil pour tester et valider des expressions régulières (regex) dans le navigateur.

## Fonctionnalités
- Saisir une regex et des cas de test
- Chaque test est marqué [OK] (doit réussir) ou [KO] (doit échouer)
- Score de précision en pourcentage
- Bibliothèque de regex prêtes à l'emploi (téléphone, email)
